**BLINK 1.3.5 is a maintenance release.** The board's firmware is the same as 1.3.4's; it takes the new version number so the two halves stay in step. The changes are in the app, and most of them are in how it is built and tested.

## What changed

- **On Windows, `blink uninstall` names your Codex settings file correctly.** It told you where your Codex trust records were left, with one slash pointing the wrong way. Windows opened that path anyway, but it is the one you are told to edit by hand.
- **Running BLINK from a source checkout gives the right instructions.** It said to undo the install with a program that a source install never creates, and that the folder you ran it from could be deleted, when the background service runs from that folder. It now names the command that works and says to keep the folder. The downloaded app is unaffected.
- **Checks that BLINK's own tests and release tools depend on are sturdier.** The Windows test run passes again, the check that watches Codex's log format follows a change in how Codex spells it, and flashing a board says plainly when the flashing tool itself is broken rather than blaming the USB port.

## Updating

Run **`blink update`** to install this version, then the screen offers the firmware and one tap installs it.

Automatic app updates are off for this release, so nothing installs on its own.
