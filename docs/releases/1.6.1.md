**BLINK 1.6.1 adds a high-contrast mode.** On a panel that looks washed out, Settings -> Display can now switch the screen to a near-black background with pure white text.

## What changed

- **Settings -> Display.** The Brightness setting is now Display: the five brightness levels, and below them the contrast, **Normal** or **High**. Changing it restarts the board into the new colours in a couple of seconds and brings you back to the Display screen; the board briefly shows that it is reconnecting while it does.
- **High contrast** is a near-black background, pure white numbers and text, and lighter labels. The green, amber and red that warn you about a limit are unchanged and were re-checked against the darker background.

There is no 1.6.0 release. An earlier contrast setting was built under that number and withdrawn before release, because it scrambled the screen on these boards; this one changes only the colours the board draws.

## Updating

Run **`blink update`** to install this version, then the screen offers the firmware and one tap installs it. Your brightness and other settings carry over.

Automatic app updates are off for this release, so nothing installs on its own.

Something wrong? Open an issue at **[github.com/gapietro/AIFBlink/issues](https://github.com/gapietro/AIFBlink/issues)** with the output of `blink status` and the last lines of `bridge.log`.
